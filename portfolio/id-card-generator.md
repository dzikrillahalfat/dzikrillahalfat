# Employee ID Card Generator

**Focus:** Web-based workflow design · PHP · SQLite · JavaScript

## Business problem
Preparing consistent employee ID cards manually involves repeatedly editing identity fields, portraits, and print layouts. Multiple card templates make the process harder to standardize.

## Solution approach
The private project documentation describes a browser-based workflow for entering a name, role, and employee ID; uploading and positioning a portrait; selecting between two card layouts; and producing print-ready assets. Optional image-background removal is handled through a configurable provider, with manual alternatives.

## Skills represented
Translating a repetitive design task into a structured workflow; form and image handling; print-output requirements; and separation of runtime configuration from source files.

**Disclosure:** This is a descriptive case study, not a live demo or a measured time-saving claim. Employee records, photographs, artwork rights, API keys, and internal source are not published here.
