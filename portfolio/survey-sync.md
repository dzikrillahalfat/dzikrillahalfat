# Multi-Location Survey Synchronization

**Focus:** Data integrity · Google Apps Script · PHP · Reporting

## Business problem
Combining survey submissions from several locations into one report risks duplicates and inconsistent regional labels, especially when a local source is reset or records are entered manually.

## Solution approach
The private project documentation describes branch-aware survey synchronization to a consolidated spreadsheet, using record identifiers and duplicate checks. The design aims to preserve historical reporting even if a source website's local records change.

## Skills represented
Designing data keys, identifying duplicate scenarios, mapping multi-source reporting, and preserving existing spreadsheet calculations and reporting structure.

**Disclosure:** No survey answers, customer information, spreadsheet links, private endpoints, credentials, or operational code are shared. The original repository contains credential-related material and must **not** be switched to Public as-is; credentials require rotation and a proper history review before any source release.
