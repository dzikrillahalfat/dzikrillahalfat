# Plumbing & Ducting Learning Game

**Focus:** Educational interaction · PHP · SQLite · JavaScript

## Learning problem
Technical routing concepts can be abstract when introduced only through static reading material.

## Solution approach
The private project documents a browser game in which players connect water-pipe and air-duct routes under an in-game budget. Its described features include progressively structured levels, player progress, and educational notes. These mechanics provide a way to explore planning trade-offs interactively.

## Skills represented
Translating domain concepts into rules, designing interactive state and scoring, and pairing a browser interface with persistence for user progress.

**Disclosure:** This is a project overview, not an independently tested demo. Original game assets and private source files are not republished here; no learning-effectiveness metrics are claimed.
